# دخل و خرج من (Daily Expense)

یک وب‌اپ ساده برای ثبت درآمد و هزینه‌های روزانه: عنوان و مبلغ رو وارد می‌کنی، جمع درآمد، هزینه و مانده خودکار حساب می‌شه. اطلاعات در مرورگر (localStorage) ذخیره می‌شه.

- **ابزار AI:** Claude (Claude Code)
- **تکنولوژی:** HTML + CSS + JavaScript (بدون فریمورک)

## سه پرامپت اصلی
1. «یک وب‌اپ ساده‌ی فارسی و راست‌چین برای ثبت دخل و خرج روزانه بساز که عنوان، مبلغ و نوع (درآمد/هزینه) بگیره و جمع درآمد، هزینه و مانده رو نشون بده.»
2. «اطلاعات رو در localStorage ذخیره کن تا با بستن صفحه پاک نشن و برای هر مورد دکمه‌ی حذف بذار.»
3. «اعداد رو با ارقام فارسی و جداکننده‌ی هزارگان نشون بده و درآمد رو سبز و هزینه رو قرمز کن.»
